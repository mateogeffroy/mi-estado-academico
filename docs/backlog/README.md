# Backlog

Trackea iniciativas en curso, antes de que lleguen al `CHANGELOG.md`. Un
archivo por iniciativa, nombrado `NNN-slug.md`.

## Convención

Cada archivo lleva:

- **Estado**: `Planeado` / `En progreso` / `Bloqueado` / `Shippeado`
- **Rama**: dónde vive el trabajo
- **Contexto**: por qué existe la iniciativa
- **Hecho**: qué ya está aplicado
- **Falta**: qué queda
- **Decisiones abiertas**: preguntas sin resolver

Cuando una iniciativa shippea, se resume en `CHANGELOG.md` y este archivo
pasa a `Shippeado` (o se borra si no aporta valor histórico).
